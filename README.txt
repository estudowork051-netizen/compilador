2. COMO COMPILAR E INSTALAR O APK DIRETO NO CELULAR (SEM ANDROID STUDIO):
===================================================================================
Se você não consegue compilar pelo Android Studio na sua máquina, utilize o GitHub Actions
gratuito que já está 100% configurado no projeto:
1. No seu repositório no GitHub (pode ser pelo navegador do celular ou PC), clique na aba "Actions".
2. O workflow "Gerar APK da Paciencia" compila o APK automaticamente a cada commit ou
   quando você clica em "Run workflow".
3. Aguarde cerca de 2 minutos até o ícone verde de sucesso aparecer.
4. Clique na execução concluída e desça até a seção "Artifacts" no final da página.
5. Clique em "Paciencia-Solitaire-APK" para baixar o arquivo ZIP com o "app-debug.apk".
6. Abra o APK no seu celular Android para instalar e jogar imediatamente!

3. COMO JOGAR O JOGO COMPLETO NO CELULAR OU PC VIA HTML:
===================================================================================
Se preferir jogar sem instalar APK ou aplicativos externos:
1. Baixe o arquivo "paciencia_web_app.html".
2. Abra-o diretamente em qualquer navegador (Google Chrome, Safari, Samsung Internet, Firefox).
3. O jogo funciona 100% offline, em tela cheia, com controles por toque/arraste e som!
4. Todas as melhorias visuais, os 5 cenários, as cartas nobres, as 8 skins, os 8 avatares,
   a dica mágica, as moedas e o botão de assistir vídeo estão ativos e funcionais!
