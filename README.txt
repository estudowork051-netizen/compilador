2. COMO COMPILAR E INSTALAR O APP NO CELULAR SEM PRECISAR DO ANDROID STUDIO:
==============================================================================================
Existem 2 formas práticas e rápidas de jogar diretamente no seu aparelho Android:

OPÇÃO A — INSTALAÇÃO DIRETA VIA NAVEGADOR DO CELULAR (MAIS RÁPIDA - 30 SEGUNDOS):
1. Baixe o arquivo "paciencia_web_app.html" para o seu celular Android.
2. Abra o arquivo no navegador Google Chrome do celular.
3. Toque no menu de 3 pontinhos (canto superior direito do Chrome).
4. Selecione a opção "Adicionar à tela inicial" ou "Instalar aplicativo".
5. O jogo será instalado no seu celular com ícone próprio de aplicativo, tela cheia,
   funcionamento 100% offline (sem internet), com sons, toques suaves e gráficos completos!

OPÇÃO B — GERAR O APK NATIVO AUTOMATICAMENTE PELO GITHUB (SEM ANDROID STUDIO NO PC):
O projeto já conta com o GitHub Actions pronto no arquivo ".github/workflows/android.yml".
1. Suba o código deste repositório para o seu GitHub (ou faça push).
2. Acesse seu repositório no GitHub (pelo celular ou PC) e vá na aba "Actions".
3. Clique no workflow "Gerar APK da Paciencia" e clique no botão "Run workflow" (Executar fluxo).
4. O GitHub compilará o aplicativo nativo nos servidores do Ubuntu em ~2 minutos.
5. Quando o workflow finalizar com ícone verde (✓), clique nele.
6. Role até o final da página até a seção "Artifacts" e baixe o "Paciencia-Solitaire-APK".
7. Dentro do ZIP baixado estará o arquivo "app-debug.apk".
8. Abra o "app-debug.apk" no seu Android para instalar o jogo nativo diretamente!
